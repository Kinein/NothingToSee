# The game state

- `G` is the current game and is what gets saved (localStorage, `saveGame` / `loadGame`). **A new field on `G`
  belongs in `freshG` with its "unset" value** (`CLAUDE.md`, *Shared globals*). `docs/STATE.md`, *`G` fields
  added on the fly*, lists the ones that are not there yet; don't add to that list.
- Only `js/game/state.js` touches storage. A lost game deletes the save, no reloading (`gameOver`).
- `docs/STATE.md` is generated by `node tools/state.js` (part of `python3 tools/check.py`): never edit it by hand.
- A change to what `freshG` holds or how a game starts changes the seeded determinism fingerprint: that is a
  behaviour change (`CLAUDE.md`, *Commands*).
