# The documents

- The code is the ground, the documents are the map. Where they disagree, say so; for `docs/DESIGN.md` ask which
  side wins (see the `design` rule).
- `MAP.md`, `SYMBOLS.tsv` and `docs/STATE.md` are generated by `python3 tools/check.py`: never edit them, and don't
  reconcile them by hand.
- After an edit run `node .claude/tools/docs-check.js` and fix what it reports for the file you touched: a backticked
  path that is not in the repo, a link or anchor that goes nowhere. `--identifiers` also lists backticked names no
  code mentions.
- `/docs-sync <CLAUDE|README|DESIGN|PERFORMANCE|FOLLOWUP|ASSETS>` reconciles a whole document with the code changed
  since its marker in `.claude/tools/docs-markers.json`.
- Docs-only changes don't bump the version.
